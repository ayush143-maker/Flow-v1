# Accessibility review checklist

Review changes to screen and shared-component UI with these checks:

- Use semantic headings in a meaningful order.
- Give meaningful images appropriate alternative text; hide purely decorative imagery from assistive technology when suitable.
- Ensure buttons and icon-only controls have understandable accessible names.
- Verify that keyboard focus remains visible and follows the visual order.
- Confirm validation errors are not communicated only through color.
- Check contrast for primary and secondary text in both light and dark themes.
- Respect reduced-motion preferences where animated transitions are used.
- Ensure long merchant names and large currency values do not obscure adjacent controls at narrow widths.

This checklist is a review aid and should not be treated as a completed accessibility audit.
